Tasks 排序／篩選 —— 控制元件放哪

2026-09-04 · 三個版型 mockup · 底圖為目前 Projects 專案詳情頁的實際排版

現況（沒有任何排序／篩選）

A　chip 即篩選 + 排序下拉（我的建議）

chip 本來就在，本來就按狀態分組，本來就顯示數字——把它變可點是「加一個 onClick 和一種未選樣式」，不新增任何區塊。 排序與另外兩個篩選是新的一小條，貼在 Tasks 標題下方。

B　全部集中在 Tasks 上方一條工具列

四個控制項排在一起，形式一致、好找。代價：左邊那三顆 chip 明明長得像按鈕卻不能點， 而且同一件事（狀態）在畫面上出現兩次。

C　兩者都要

我的建議：A。 那三顆 chip 已經是「按狀態分組並顯示數量」——它在視覺上早就是一組篩選器了，只是點不下去。 把它變可點，是刪掉一個落差，不是加一個功能。
B 的問題不在於難做，在於它讓 chip 繼續當一個「看起來能按但不能按」的東西；C 則是同一份 state 開兩個入口， 多出一條同步邏輯換不到新能力。

三個版型的資料層完全相同（user_settings 一筆 projectTaskView），差別只在使用者從哪裡改它。
