平板版 UI 草圖（直向 820、橫向 1180 基準）

平板是「功能接近桌機、操作改成觸控」：完整保留甘特與拖移，版面改成左側窄導覽＋主從雙欄。

設計原則
  • 左側窄導覽列（圖示＋文字）取代桌機的上方分頁，騰出垂直空間。
  • 橫向＝主從雙欄：左邊專案清單、右邊任務詳情；直向＝單欄，點進去看詳情。
  • 保留甘特圖與拖移排序：甘特左欄固定、右邊橫向捲動；拖移把手加大（觸控友善，最小 44px 點擊區）。
  • Data 資料表保留（精簡欄位、可橫向捲動）；Settings、帳號管理保留在導覽最下方。
  • 滑過（hover）的提示全部改成點擊或長按。
