手機版 UI 草圖（390 寬基準）

以「看進度、查自己的事、勾選完成」為主；重編輯（資料表、設定、批次）留給桌機。橫向可捲動看全部畫面。

設計原則
  • 首頁是「我的任務」：手機最常見的問題是「我今天要做什麼」。
  • 底部分頁列（拇指好按）：我的任務／總覽／專案／時程／更多。
  • 不放甘特圖：時程改成每個專案一條簡化橫條＋點進去看任務清單；要看完整甘特請用平板或桌機。
  • 編輯用底部抽屜：點任務跳出抽屜，欄位上下排；拖移排序改成長按把手（先不做，列為之後）。
  • 不做：資料表（Data）、設定、帳號管理、批次操作、備份——都放「更多」並提示請用桌機。

Overview 三塊保留 Upcoming、Status；Timeline 改簡化橫條（在「時程」頁）
My Tasks首頁，含「我關注／我執行」標籤

任務與子任務拖移排序先不做（手機誤觸多）；之後可做長按把手
Timeline 甘特圖簡化橫條；完整甘特見平板／桌機
Data 資料表、批次、匯入匯出不做，請用桌機
Settings、帳號管理、備份不做，放「更多」並提示用桌機
個人設定（縮放、時間尺度等）沿用同一組帳號設定；手機版不提供欄寬／高度調整
