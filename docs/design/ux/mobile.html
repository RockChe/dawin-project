可以點的路徑

  1. 底部分頁列切換五個畫面
  2. 專案 → 點專案卡 → 詳情；麵包屑「專案」返回
  3. 時程 → 點一條橫條 → 詳情，麵包屑變成「首頁 › 時程 › 名稱」，返回回到時程
  4. 點任務卡開抽屜；點「關注人」輸入框會出現鍵盤示意；改狀態或關注人後「儲存」才可按
  5. 我的任務：點狀態 chips（可多選）、選「暫緩」看篩選後沒結果
  6. 展開子任務、勾選；把最後一個勾起來會有完成提示
  7. 更多 → 顯示雲寶寶開關／登出

雲寶寶職責

雲只是輔助：每個畫面最多 3 種；旁邊一定有文字；關閉後換成色點／純文字。
