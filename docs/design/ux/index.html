五朵雲各自的職責

雲代表出現在
規則：雲只做輔助，旁邊一定有文字；資料表、設定、帳號管理不放雲（除了「顯示雲朵」開關）；只有兩種動態（載入上下飄、完成時筋斗雲飛過），尊重「減少動態」；個人設定可關閉雲朵。

需要你決定的設計取捨

#議題設計師的做法
1「每畫面最多 3 種雲」與「KPI 四朵雲＋分組雲＋天氣預報五朵雲」衝突手機版守規則（我的任務只用 3 種）；桌面／平板依你指定的對應做到 4～5 種。建議規則改成「最多 5 種、同一區塊內不重複」。
2頁首白雲 Logo 在資料表與設定頁是否保留保留（品牌識別，不算內容雲）
3勾完最後一個子任務是否自動把任務標成已完成桌面示意為「自動」，平板只提示「可以改成已完成了」；現行產品不會自動改，要做的話需另外決定
4專案詳情的子任務預設全展開或可收合設計為可收合（預設只展開前兩個任務）
5色彩對比共用樣式已把文字色調到 AA（4.5:1）；產品現有主題也有同樣問題，實作時要一併調整
